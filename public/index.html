Why this exists

repoask-mcp answers questions about someone else's GitHub repo, grounded and cited against the actual source instead of generated from scratch. I wanted the same thing pointed at myself: an agent that can answer real questions about my work using my resume and project history as the retrieval corpus — not whatever a model happens to already know (or guess) about me.
